# Contributing to Unsubbed

Thanks for helping keep good software free. 💛

## Send your improvements back
If you've changed or improved this app, please share it with everyone. Open a **pull request** on this repository so your fix reaches every user, not just your copy.

1. Fork this repository.
2. Make your change on a new branch.
3. Open a pull request that explains **what** you changed and **why**.

New to pull requests? Opening an **issue** that describes your idea is welcome too.

## The license (AGPL-3.0) in plain words
- You may use, copy, change and share this app for free.
- If you **share a modified version**, or **run it as a service for other people**, you must publish your changes under the same AGPL-3.0 license.
- See [LICENSE](LICENSE) for the full terms.

## A few rules
- **Be respectful.** Everyone here is a volunteer or a user.
- **AI-assisted code is fine, but a human must have reviewed it and must vouch for it.** Say in your pull request if AI helped.
- **Report security problems privately** using GitHub's "Report a vulnerability" button, not a public issue.
- **No brand assets from other companies.** No logos, fonts, templates or sample files. Keep everything original.
- No paid bug bounties are offered.

## Support the project
Unsubbed apps are free forever. If one saves you a subscription, consider supporting development at **[ko-fi.com/unsubbed](https://ko-fi.com/unsubbed)**.
